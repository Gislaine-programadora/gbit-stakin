🚀 GBIT-Stakin CLI

Staking Profissional para Web3 — rápido, seguro e funcional.

Ver no npm Ver no GitHub

📦 Instalação

Instale globalmente via npm:

npm install -g gbit-stakin

🧭 Comandos principais

npx gbit-stakin init "meu-projeto"   # Cria um novo projeto
npx gbit-stakin balance              # Mostra saldo atual
npx gbit-stakin stake 100            # Faz staking de 100 tokens
npx gbit-stakin unstake 50           # Retira 50 tokens
npx gbit-stakin price                # Exibe dados de mercado
npx gbit-stakin help                 # Lista todos os comandos
npx gbit-stakin approve              # Aprova tokens para staking
