## 📦 Instalação


```bash
npm install -g gbit-stakin
```

🚀 Instalação
# Global NPM CLI

```bash
npx gbit-stakin init "meu-projeto"
```

🔧 Configuração Avançada (.env)

```bash
PRIVATE_KEY=0xSuaChavePrivada
RPC_URL=https://eth-mainnet.g.alchemy.com/v2/SUA_KEY
STAKING_CONTRACT=0xSeuContratoStaking
WALLET_ADDRESS=0x297e1984BF7Da594a34E88Ecadf7B47bBbb3A5c2
```


# Stakin-gbit projeto iniciar


```bash
npx gbit-stakin init "meu-projeto"
```

```bash
npx gbit-stakin price
```


```bash
npx gbit-stakin balance
```


```bash
npx gbit-stakin stake 40
```

# Unstake (Saque)

```bash
npx gbit-stakin unstake 20
```

```bash
npx gbit-stakin help
```

```bash
npx gbit-stakin approve
```
