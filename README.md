## CLI Staking Web3 Real para projetos gbit - Balance, Stake, Unstake, Market Data

✨ Comandos Disponíveis
Comando	Descrição	Exemplo

balance	💰 Dashboard completo	gbit-stakin balance

stake	🔥 Depositar no projeto	gbit-stakin stake "MeuProjeto" 100

unstake	💸 Retirar liquidez	gbit-stakin unstake 50

price	💎 Preços e APY	gbit-stakin price

🚀 Instalação
# Global NPM CLI


```bash
gbit-stakin unstake 2500
```


# stakin-price

```bash
npx gbit-stakin price
```


💻 Como Usar
1. Dashboard Completo

```bash
npx gbit-stakin balance
```

2. Stake em Projeto

# Default 100 GBIT

```bash
npx gbit-stakin stake "MeuProjeto"
```

# Quantidade custom

```bash
npx gbit-stakin stake "GbitApp" 100
```
